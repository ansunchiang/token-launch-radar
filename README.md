Signal Atlas is an offline radar for protocols that record no token in the frozen DefiLlama snapshot. It blends category multiples with related protocols and TVL-matched market peers, then adjusts for weekly TVL change, chain breadth, and time tracked. Every ranked protocol includes a farm plan with entry checks, estimated costs, monitoring, and an exit.

With Node 22.18 or newer and the bounty kit next to this repository, run `MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json` and open `out/dashboard/index.html`. The same run writes `out/board.json` and `out/dossier.json`.
